# 今日事报 · 待办与复盘

复古报纸风格的待办事项 + 每日复盘网站。任务像新闻稿一样"刊登"，完成后盖"已办"章；复盘以"社论"形式刊发，整版报纸可导出 PNG 分享。

## 功能

- **日刊**：当日待办（刊登 / 划记完成 / 双击改稿 / 撤稿 / 筛选）+「今日社论」每日复盘
- **周刊**：「一周综述」周复盘 + 本周办讫纪事（自动汇总）+ 每日社论存档
- **月刊**：「本月特刊」月复盘 + 本月办讫纪事 + 各周综述存档
- **印刷发行**：整版报纸导出为 PNG 图片（html2canvas，已本地打包）
- **翻期**：前一期 / 后一期 / 回到本期，可回看任意往期报纸
- 数据存于浏览器 localStorage，社论自动保存
